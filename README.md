# stock-investment-analytics
This repository is used to store my FYP project which is a stock investment decision analytics for novice investors.

## Dataset Source
The raw stock price datasets in `data/raw-stock-price-dataset/` are sourced from Yahoo Finance via the `yfinance` Python library.
The current download range is from `2021-01-01` to `2025-12-31` (implemented with an exclusive end date of `2026-01-01`).
